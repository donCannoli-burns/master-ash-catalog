# Contributing

Contributions are welcome: source provenance, historical dates, author/player mappings, broken links, current KoLmafia compatibility notes, and license evidence are all useful.

For a new script source, prefer the original repository/forum thread over a later copy. Do not remove original copyright/license notices. If redistribution permission is unclear, add metadata/provenance first and leave bytes unvendored.

Generated content under `docs/` should be changed through the Go generator rather than edited by hand.
